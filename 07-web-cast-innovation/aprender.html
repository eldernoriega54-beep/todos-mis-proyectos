Aprende a Programar

La programación es el idioma del futuro. A través de un entorno visual basado en bloques de colores (similar a Scratch y LEGO Spike), los estudiantes pueden dar instrucciones precisas a sus creaciones de forma intuitiva.

Cada bloque representa una acción: avanzar, girar, encender luces o leer sensores. ¡Al unirlos, crean algoritmos complejos con facilidad!

Conexiones con un Robot

Un robot es la unión perfecta entre hardware (componentes físicos) y software (programa). Aprenderás a identificar el "Cerebro" (Hub), donde se conectan los motores y los sensores mediante cables y puertos específicos.

Además, podrás emparejar tus dispositivos móviles o tablets con el robot utilizando conectividad Bluetooth para enviar tus códigos de manera inalámbrica.

🔌🤖

Unión: Código y Conexión

La verdadera magia ocurre cuando el código interactúa con el mundo físico. Si programamos "Avanzar si el sensor detecta un obstáculo", el cerebro del robot lee la conexión del sensor y ejecuta la acción en los motores conectados.

Este ciclo de retroalimentación enseña pensamiento computacional y causa-efecto en tiempo real.
